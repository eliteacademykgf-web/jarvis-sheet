# Сквозная аналитика на офисном ПК

Скрипт раз в час забирает данные из AmoCRM и Meta и обновляет Google-таблицу.
Это не бот и не сайт: окно просто висит свёрнутым и раз в час делает работу.
Работает, пока ПК включён и в Windows выполнен вход (как сервер сайта Elite).

Понадобится: интернет, Python 3.12 (уже стоит, если на ПК работает сайт Elite)
и флешка с двумя файлами — `.env` и `google-key.json` (их нет в git).

## 1. Скачать код

**Вариант А — клон (можно будет обновлять одной кнопкой).** Нужен доступ
к приватному репозиторию `nurza777/jarvis-meta`:

    cd /d D:\
    git clone https://github.com/nurza777/jarvis-meta.git

Код окажется в `D:\jarvis-meta\jarvis-sheet`.

**Вариант Б — с флешки.** Скопировать папку `jarvis-sheet` целиком
в `D:\jarvis-meta\jarvis-sheet`. Обновлять тогда тоже копированием.

## 2. Положить секреты

В папку `jarvis-sheet` скопировать с флешки:

- `.env` — токены AmoCRM и Meta, id таблицы;
- `google-key.json` — ключ сервисного аккаунта Google.

Проверить, что имена точные, а не `.env.txt` / `google-key.json.json`:

    dir /a D:\jarvis-meta\jarvis-sheet

После переноса удалить файлы с флешки. Не пересылать их через мессенджеры
и почту.

## 3. Доступ к таблице

Открыть JSON-ключ в Блокноте, найти строку `"client_email"` (адрес вида
`…@….iam.gserviceaccount.com`). В Google-таблице: **Настройки доступа** →
добавить этот адрес с ролью **Редактор**, галочку «Уведомить» снять.

## 4. Ручной лист заказчика — ничего делать не нужно

Скрипт ведёт свои листы «Сквозная аналитика <Месяц>». Если в таблице уже
есть лист с таким же названием, заполненный вручную, при первом запуске
скрипт:

- переименует его в «Сквозная аналитика Сентябрь (вручную)», ничего в нём
  не меняя;
- перенесёт с него кодовые слова и статусы на лист `ads_manual`
  (объявления сопоставляются по названию);
- рядом создаст свой лист месяца.

Дальше кодовые слова и статусы заполняются на листе `ads_manual`: скрипт
сам добавляет туда новые объявления с пустыми полями, а строки, которые уже
есть, не трогает. На листе месяца правки затираются при каждом обновлении.

## 5. Запустить

Двойной клик по `start-sheet.bat`. Первый запуск дольше: ставятся пакеты.

В окне должно появиться:

    Обновляю таблицу (вчера и сегодня)...
      2026-09-24  meta_daily: +11 / обновлено 0 ...
      Лист «Сквозная аналитика Сентябрь» пересобран ...
    Готово.
    Следующее обновление в 18:05

Окно не закрывать, можно свернуть. Всё, что в нём пишется, дублируется
в `logs\sheet.log`.

## 6. История за прошлые дни

Часовое обновление трогает только вчера и сегодня. Прошлые дни заливаются
один раз, в отдельном окне командной строки:

    cd /d D:\jarvis-meta\jarvis-sheet
    py -3.12 write_to_sheets.py 2026-08-01 2026-09-24

Месяц идёт примерно 10 минут (AmoCRM отвечает не быстро).

## 7. Автозапуск и сон

- `install-autostart.bat` — окно будет само открываться при входе в Windows.
  Отключить — `uninstall-autostart.bat`.
- Если на ПК ещё не запускали `keep-awake.bat` из папки сайта Elite —
  запустить: во сне ПК таблица не обновляется. После пробуждения скрипт
  сам обновит таблицу в ближайшие :05.

## 8. Уведомления о сбоях (желательно)

Если токен истечёт или пропадёт интернет, таблица перестанет обновляться
молча. Чтобы об этом приходило сообщение в Telegram, в `.env` заполнить:

    ALERT_BOT_TOKEN=токен любого бота (@BotFather → /newbot)
    ALERT_CHAT_IDS=ваш chat_id (узнать у @userinfobot), можно несколько через запятую

Каждый получатель должен один раз написать этому боту `/start`.
Изменения `.env` подхватываются со следующего часа, перезапуск не нужен.

## Обновление кода

Вариант А: `update-sheet.bat` (делает `git pull`). Перезапускать окно не нужно —
следующий час уже пойдёт на новом коде.

## Если что-то не так

| В логе | Что делать |
|---|---|
| `Токен AmoCRM истёк или неверный` | Новый долгосрочный токен в AmoCRM → `AMO_TOKEN` в `.env` |
| `Meta API error 190` | Токен Meta истёк или отозван → новый `META_TOKEN` |
| `Нет доступа к таблице` | Шаг 3: сервисный аккаунт не редактор таблицы |
| `Ручной лист … сохранён как …` | Всё в порядке: так бывает один раз, при первом запуске |
| `Обновление таблицы уже запущено в другом окне` | Всё в порядке, второе окно можно закрыть |
| Окно закрылось само | Запустить `start-sheet.bat` снова, посмотреть `logs\sheet.log` |
